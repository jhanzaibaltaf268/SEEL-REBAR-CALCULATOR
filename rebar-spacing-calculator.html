How to use: Rebar Spacing Calculator

  1. Enter the total width and the edge cover on each side.
  2. Enter the desired spacing (centre-to-centre).
  3. Pick the bar size — it sets the clear gap.
  4. Read the bar count, the actual spacing achieved and the clear gap.
  5. Check the actual spacing against the code limits below before fixing the layout.

Formula

Number of bars = floor((width − 2 × cover) ÷ spacing) + 1. Actual spacing = reinforced width ÷ (bars − 1).

See the full rebar weight chart (kg/m & lb/ft) →

Why subtract cover twice? The bars stop one cover short of each edge, so the width they actually span is the total width minus two covers — that is the reinforced width. Why +1? Bars sit at both ends of the reinforced width plus one per spacing interval — without the +1 you would be one bar short. Why is the actual spacing not the spacing you asked for? Bars must be whole numbers, evenly spread. The calculator rounds the count up to the next whole bar and re-spreads them, so the actual spacing is usually slightly larger than the desired spacing (see the table below).

Worked example 1: 3,000 mm width (defaults)

Width 3,000 mm, 50 mm cover each side, desired spacing 150 mm, 12 mm bars. These are the values the calculator opens with, so you can check the result immediately:

  1. Reinforced width: 3,000 − 2 × 50 = 2,900 mm.
  2. Number of bars: floor(2,900 ÷ 150) + 1 = 19 + 1 = 20 bars.
  3. Actual c/c spacing: 2,900 ÷ (20 − 1) = 152.63 mm — slightly more than the 150 mm asked for, because 19 gaps must cover 2,900 mm.
  4. Clear gap between bars: 152.63 − 12 = 140.63 mm.

Try it yourself: enter the same numbers in the calculator above and you will get the same result.

Worked example 2: 4,000 mm width

Width 4,000 mm, 50 mm cover, desired spacing 200 mm, 16 mm bars:

  1. Reinforced width: 4,000 − 2 × 50 = 3,900 mm.
  2. Number of bars: floor(3,900 ÷ 200) + 1 = 19 + 1 = 20 bars.
  3. Actual c/c spacing: 3,900 ÷ 19 = 205.26 mm.
  4. Clear gap: 205.26 − 16 = 189.26 mm.

Same bar count as example 1, different spacing — the count follows the width and the target spacing together, never one alone.

Edge cover guide

SituationTypical cover each side
Slab on grade40–50 mm (about 1.5–2 in)
Concrete cast against earth (footings)75 mm (3 in)
Beams, columns, walls (formed)40 mm, or as drawn

Cover is the distance from the concrete face to the bar — it protects the steel from corrosion and fire. Always use the value on your drawing when one is given; this table is for early estimates only.

Code spacing checks (ACI 318)

Two checks govern whether a spacing is acceptable. They are code limits, not calculator inputs — run them on the calculator's outputs:

CheckRuleExample 1 result
Minimum clear spacingThe larger of 25 mm (1 in), one bar diameter, or 1.33 × aggregate sizeClear gap 140.63 mm ≥ max(25, 12) — passes
Maximum c/c spacing (slabs, beams)The smaller of 3 × slab thickness or 450 mm (18 in)Actual 152.63 mm ≤ 450 mm for a 150 mm slab — passes

The minimum exists so concrete can flow around the bars and bond to them; the maximum exists to control cracking and spread the steel. If either check fails, change the bar size, the spacing, or the member width — the calculator alone does not enforce them.

What the calculator does not include

  • Bar length and weight. This tool lays out one width. For lengths and weights use the slab calculator or the weight calculator.
  • Two-way grids. A slab mat runs both directions — this tool spaces one direction at a time. The slab calculator counts both.
  • Required steel area. This tool does not size reinforcement from loads. If your design gives a required steel area, that is a different calculation from this spacing layout.
  • Lap, hook and bend lengths. Splice and anchorage detailing come from the lap calculator and the hook calculator.
  • Aggregate size. The minimum-clear check needs the largest aggregate size; this tool does not ask for it, so run that check by hand.

5 common mistakes

  1. Measuring the clear gap instead of centre-to-centre. Spacing is centre-to-centre. Measuring face-to-face under-counts the bars.
  2. Forgetting cover on the second side. The reinforced width loses cover at both edges, not one. Subtracting it once overstates the width and the bar count.
  3. Rounding the bar count down. The count always rounds up (floor + 1). Rounding down leaves the last gap wider than designed.
  4. Entering metres instead of millimetres. Width, cover and spacing are all in millimetres here. Entering 3 instead of 3,000 breaks the result completely.
  5. Ignoring the maximum spacing. A layout can satisfy the count and still violate the 3 × thickness / 450 mm maximum on thin slabs — always run the code checks.

Last reviewed: October 2026. Code checks summarise ACI 318 spacing rules for guidance only — always verify against your structural drawings and governing code.

Rebar Spacing Calculator — FAQ

How do you calculate rebar spacing?

Subtract cover from both sides of the width, divide by the desired spacing, and add one for the number of bars: bars = floor((width − 2 × cover) ÷ spacing) + 1. Then re-spread evenly: actual spacing = reinforced width ÷ (bars − 1).

What is the minimum spacing between rebars?

The clear gap must be at least the largest of 25 mm (1 in), one bar diameter, or 1.33 × the largest aggregate size (ACI 318). For 12 mm bars with ordinary aggregate, 25 mm usually governs — check your code and your aggregate size.

Why is the actual spacing different from the spacing I entered?

Because bars must be whole numbers, evenly spread. The calculator rounds the count up and re-divides the reinforced width, so the actual spacing is usually slightly larger than desired — 150 mm asked gives 152.63 mm on the 3,000 mm default width.

What is the difference between c/c spacing and clear gap?

Centre-to-centre (c/c) spacing is centre of one bar to centre of the next; the clear gap is the open space between bar faces, which is the c/c spacing minus one bar diameter. Codes limit the clear gap at the minimum end and the c/c spacing at the maximum end.

How much cover should I use?

Slabs on grade typically 40–50 mm, concrete cast against earth 75 mm, formed beams and columns 40 mm or as drawn. Always use the drawing's value when one is given — cover protects the steel from corrosion and fire.

What is the maximum spacing allowed?

For slabs and beams, ACI 318 caps main reinforcement spacing at the smaller of 3 × slab thickness or 450 mm (18 in). On a 150 mm slab that cap is 450 mm; on a 100 mm slab it is 300 mm.

Can I use this calculator for beams, columns and walls?

Yes — any single width works: enter the member width, cover and target spacing. For a two-way slab mat, use the slab calculator, which counts both directions.

What if my spacing is too tight?

If the clear gap falls below the minimum, switch to smaller bars (more bars, smaller diameter, larger gaps) or widen the member. Do not just delete bars — that changes the steel area the design relies on.

Does spacing affect the amount of steel?

Yes, directly. Tighter spacing means more bars across the same width, and the total length and weight grow with the count. Compare the desired-spacing table above: 100 mm needs 30 bars where 300 mm needs 10 on the same width.

Can I use imperial units?

The calculator takes millimetres, but the conversions are direct: 12 mm is a #4 bar, 150 mm is about 6 in, 50 mm is 2 in, and 3,000 mm is 9.84 ft. Convert first, then enter millimetres.
