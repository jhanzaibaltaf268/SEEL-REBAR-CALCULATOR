Column Rebar Calculator

Estimate the steel in a column. Enter the column size and height, the number and size of vertical bars, plus the tie spacing and size — the tool returns vertical steel, tie steel and the total weight.

How to use it

  1. Enter column height and cross-section.
  2. Set the number and size of vertical bars and the lap allowance.
  3. Set tie spacing and bar size for the total.

Formula

Vertical steel = bars × (height + lap) × kg/m. Ties = floor(height ÷ spacing) + 1, each at the stirrup cutting length.

Questions

How is column rebar calculated?

Add the vertical bar weight to the tie weight; ties use the stirrup cutting-length method.

How many vertical bars in a column?

A minimum of 4 for rectangular and 6 for circular columns, subject to design.
